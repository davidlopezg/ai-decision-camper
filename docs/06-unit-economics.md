## 4. CAC máximo por canal (vertical Camper)

> **Fórmula:** CAC máx = LTV × margen seguridad.

**LTV Camper estimado a 24 meses:** ~250–350€ / usuario.

**Asumimos LTV = 300€** y margen de seguridad del 50%.

**CAC máximo permitido:** **150€ / usuario cualificado**.

### Por canal

| Canal | CAC realista (ES, 2025) | Viabilidad |
|---|---|---|
| **Google Search Ads** (long-tail comercial) | 0,50–2,00€ por clic → ~25–100€ por conversión a "visita cualificada" | ✅ Viable si LP convierte bien |
| **Google Search Ads** (genérico) | 1–5€/clic → 50–250€/lead cualificado | ⚠️ Marginal |
| **Meta Ads** (retargeting) | 0,30–1€/clic | ✅ Muy rentable |
| **Meta Ads** (prospecting) | 0,50–2€/clic | ⚠️ Necesita LP potente |
| **TikTok Ads** | 0,20–0,80€/clic | ✅ Barato, calidad media |
| **YouTube Ads** | 0,05–0,30€/view | ⚠️ Cualificación baja |
| **SEO orgánico** | ~0€ (lento) | ✅ Mejor a largo plazo |
| **YouTube orgánico** | ~0€ (tiempo) | ✅ Complemento |
| **Email / retargeting** | ~0,05€/contacto | ✅ Muy rentable |

## 6. Sensibilidad — qué variable más afecta

Análisis de sensibilidad simplificado: **si cada parámetro varía un 20%, cómo impacta al revenue bruto de Camper (1.316€)**:

| Parámetro | Impacto si ×0,8 | Impacto si ×1,2 |
|---|---|---|
| % completa | -14% | +14% |
| CTR afiliado | -4% | +4% |
| Conv comercio | -4% | +4% |
| AOV | -11% | +11% |
| Comisión | -11% | +11% |
| % CPL | -18% | +18% |
| CPL unitario | -18% | +18% |

**Las variables más sensibles son:** CPL unitario, % CPL, AOV, comisión. **Por eso, en el experimento 1, hay que medir el CTR y el %CPL con precisión.**
