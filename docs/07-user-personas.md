# 07 · USER PERSONAS

> **Estado:** BORRADOR INICIAL — basadas en hipótesis del mercado camper ES.
> **Cuándo validar:** tras experimento 1, con datos reales de comportamiento.

---

## Marco general

Las personas siguen la lógica definida en el brief:

> Priorizar la persona con **mayor intención + mayor ticket + mayor probabilidad de conversión**.

Para el vertical **Camper / Vanlife**, identificamos 6 personas.

---

## PERSONA A — "El planificador"

> *"Quiero comprar pero no sé qué necesito para mi furgo."*

| Atributo | Detalle |
|---|---|
| Nombre | Carlos, 35–50 años |
| Vehículo | Furgoneta mediana (VW Caddy, Renault Trafic, Citroën Berlingo) |
| Experiencia | Primera camperización o primer equipamiento serio |
| Presupuesto | 1.000–4.000€ |
| Intención | Alta, pero no sabe por dónde empezar |
| Duda principal | "¿Qué necesito realmente vs. qué me sobra?" |
| Frustración | Demasiada información contradictoria en YouTube y foros |
| Dispositivo | Móvil + desktop |
| Fuente de tráfico | TikTok, YouTube, Google ("kit camper X") |
| Ticket medio | 1.500–3.000€ |
| Probabilidad conversión | Media-Alta si el configurador le da claridad |
| **Prioridad para nosotros** | **🟢 ALTA** |

**Por qué le ganamos:** un asistente que le pregunte vehículo, uso, presupuesto y le monte un kit coherente vale oro para él.

---

## PERSONA B — "El que ya sabe qué categoría quiere"

> *"Quiero una nevera portátil pero no sé cuál."*

| Atributo | Detalle |
|---|---|
| Nombre | Laura, 28–45 años |
| Vehículo | Furgoneta camper o coche + tienda |
| Experiencia | Ya tiene algo de equipamiento, busca upgrade |
| Presupuesto | 300–1.500€ |
| Intención | Alta (compra específica) |
| Duda principal | Marca, capacidad, compresor vs. absorción, autonomía |
| Frustración | Comparadores superficiales, reviews patrocinadas |
| Fuente | Google ("mejor nevera portátil furgoneta"), Amazon, YouTube |
| Ticket | 500–1.500€ |
| **Prioridad** | **🟢 ALTA** |

**Por qué le ganamos:** comparador con IA + explicación + enlaces trazables es exactamente lo que busca.

## Priorización para el MVP

```
ORDEN DE PRIORIDAD EN EL MVP:

1. PERSONA D — presupuesto cerrado  (alta conversión, fácil de configurar)
2. PERSONA A — planificador          (descubrimiento, alto valor)
3. PERSONA B — categoría específica  (alta conversión)
4. PERSONA F — proyecto completo     (alto ticket, fase 2)
5. PERSONA E — restricciones         (fase 2)
6. PERSONA C — comparador            (complemento, fase 2)
```

**Las primeras 3 son las que el MVP debe atender bien.** Las otras 3 se añaden en fase 2 cuando el motor esté validado.
